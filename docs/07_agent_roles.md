# Agent Roles

Agents are coordinators and reviewers around deterministic Python jobs.

- Data Steward: source contracts, adjustments, quality checks, point-in-time lineage.
- Literature Scout: finds papers and extracts testable methods with citations.
- Hypothesis Agent: proposes hypotheses; cannot mark them validated.
- Feature Agent: proposes feature definitions and timing; Python implements them.
- Experiment Agent: creates registered configs and runs jobs.
- Quant Validator: audits split logic, leakage, baselines, costs, and uncertainty.
- Regime Analyst: labels market states using only available history.
- Alpha Librarian: stores candidates, metrics, lineage, and invalidation status.
- Research Narrator: optional Claude/OpenAI summaries of already-computed artifacts.
- Review Agent: challenges claims and checks reproducibility.

No agent may write numeric results directly into an artifact. Numeric artifacts are generated by code and checksummed.
