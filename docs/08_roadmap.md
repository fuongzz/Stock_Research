# Roadmap

## Phase 0 — baseline (delivered)

Typed schemas, data contract, deterministic feature builder, stock-window construction, KMeans/HDBSCAN option, forward evaluation, walk-forward report, tests, provider interface, and research docs.

## Phase 1 — data integrity

Implement vendor adapters, immutable raw snapshots, corporate actions, symbol mapping, point-in-time universe membership, and quality dashboards.

## Phase 2 — robust EXP-001

Fit transforms per fold, add overlapping-label embargo, costs/liquidity, cluster stability, bootstrap confidence intervals, baselines, and regime conditioning.

## Phase 3 — fingerprint and analogue services

Persist fingerprints, nearest historical analogues, regime labels, and a query API with lineage.

## Phase 4 — validated alpha library

Alpha DSL, trial ledger, multiple-testing controls, portfolio construction, paper trading, and independent validation.

## Phase 5 — multi-agent operations

Scheduler, task queue, human review gates, optional OpenAI/Claude narratives, and a research dashboard. Live layer remains read-only until separately approved.
